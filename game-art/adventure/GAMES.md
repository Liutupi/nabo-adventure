# 六个新游戏的玩法

版本 0.1 · 2026-10-25

每个游戏都遵守 `DESIGN.md` 的统一规则：一条资源条（0–1000）、撞到扣 250、资源归零进入结束、一个主成绩、三档门槛、固定 60 Hz、mulberry32 随机数、整数运算（C3 没有浮点单元）。下文的数字都是**起始值**，在原型里调。

**开发顺序**按地图解锁顺序：小火车 → 萤火虫 → 登山 → 滑雪 → 热气球 → 太空。每个游戏按 nabo-passport-game skill 的 M0–M4 走：先在原型里做出来并定参数，录对拍轨迹，再写 C。

画面模式（共用引擎）：

| 模式 | 做法 | 目标帧率 | 用在 |
|---|---|---|---|
| V 竖向 | ST7789 硬件竖向滚动，每帧只补新露出的几行（深潜的做法） | 60 fps | 登山、滑雪 |
| H 横向 | 背景只随高度变化（上下渐变 + 远景剪影），左右滚动不重画；只重画精灵和底部地面带 | 30 fps（待实测） | 小火车、热气球 |
| F 固定 | 镜头基本不动，脏矩形刷新（现在的 `adv_gfx`） | 30 fps | 萤火虫、太空 |

## 1. 小火车送信 POST（站 3 · 铁路平原 · 资源：蒸汽）

### 玩法

320×240横屏。NABO 开一列小蒸汽火车从左往右。轨道有上、下两条，前面会出现岔口和车站。

- 每节车厢挂一封信，信封有颜色（红、蓝、黄，后期加绿）。
- 车站在上轨或下轨，站牌颜色表示收哪种信。
- 到岔口前按 **UP / DOWN** 选上轨或下轨（岔口前 1.5 秒显示箭头提示）。
- 开到对的车站时**点 OK** 卸下最前面那节车厢的信，成绩 +1，车厢少一节。
- 开过车站没卸、或者在错的车站卸：扣 250 蒸汽。
- **按住 OK** 鸣笛：前方轨道上的羊和牛会走开；不鸣笛撞上扣 250。鸣笛每秒消耗 30 蒸汽。
- 蒸汽每秒自然消耗 20；路上的煤堆（开过去自动拾取）补 300。
- 车厢送完时到车库补满 3–5 节（新颜色随机），这时速度 +8%。

### 主成绩

送达的信数。门槛 5 / 12 / 25。

### 画面（H 模式）

```
┌────────────────────┐
│ 蒸汽 ▮▮▮▮▮▯▯   12  │ 外壳的资源条和成绩
│   天空渐变          │ 上半屏只随高度变化，左右滚动不重画
│   远山剪影          │
│ ┌红┐               │ 站牌
│══════╪═══ 上轨 ═════│ 下半屏地面带（约 120 px）每帧重画
│     ╱              │
│═[车][车][车头]═ 下轨═│ 火车头固定在屏幕左边 1/3
│ 草地 / 枕木         │
└────────────────────┘
```

### 起始参数

| 参数 | 值 |
|---|---|
| 初速 | 90 px/s，每轮补车 +8%，上限 200 px/s |
| 岔口间距 | 2.5–4 秒行程 |
| 车站出现 | 每个岔口后 60% 概率 |
| 羊/牛 | 第 3 轮后出现，每 6–10 秒一只 |
| 鸣笛判定 | 鸣笛开始后 0.6 秒内羊/牛离开 |

### NABO 动作

列车员帽 + 背带裤（第二款服装：邮差制服）。NABO 从车头窗口露出上半身：车窗待机 6 帧、拉汽笛 6、甩信 6、被撞晃 6、送达欢呼 6。

## 2. 萤火虫 NIGHT（站 4 · 夜林 · 资源：精神）

### 玩法

320×240横屏，三键朝下。NABO 在三簇草丛之间挪动，追着短暂亮起的萤火虫举罐；完整规则见`NIGHT_DESIGN.md`。

- 按横拿后的实体位置：**左侧OK左挪 / 中间DOWN举罐 / 右侧UP右挪**。标题、暂停和结算也用中键确认。
- 光点只在对应草丛盘旋1.8秒，随后消失；三簇洗牌轮换，不会都经过中间。移到亮起的一簇，中键抓到+1。
- 精神每秒消耗 25（NABO 打哈欠），每抓到一只补 60。
- 另一簇偶尔出现飞蛾诱饵：抓到扣250，不替代真正的萤火虫机会。
- 抓得越多，机会间隔越长、诱饵越多；精神耗尽结束。固定一簇等不能达铜章，移动才有实际收益。

### 主成绩

抓到的萤火虫数。门槛 15 / 35 / 60。

### 画面（F 模式）

背景是暗色渐变 + 草丛剪影，萤火虫是程序画的光点（`ag_glow`），只重画移动的光点和 NABO。

### NABO 动作

睡衣 + 玻璃罐（第二款：露营外套）。坐着待机 8、挪动 4（左右各一套，帽标不能镜像）、伸手抓 6、举罐 6、打哈欠 6。

## 3. 登山 CLIMB（站 5 · 雪山 · 资源：体力）

### 玩法

竖向往上爬。左右两面岩壁，NABO 抓在一边。

- **点 OK** 换到另一边的岩点（自动往上一格）。
- **按住 OK 蓄力、松开**：跳两格，蓄力越久跳得越远（最多 3 格）。
- 抓着不动时体力每秒消耗 40；爬一格补 15；岩缝里的水壶补 250。
- 岩点有三种：普通、会碎（抓上 1 秒后掉落）、结冰（抓上后体力消耗翻倍）。
- 落石从上面掉下来，看准时机换边。撞上扣 250 并往下滑一格。

### 主成绩

高度（米），1 格 = 1 米。门槛 50 / 150 / 300。

### 画面（V 模式）

和深潜一样的硬件竖向滚动，方向向上。岩壁用 32×32 图块拼，高度越高颜色越冷、雪越多（雪地图块和滑雪共用）。

### NABO 动作

登山服 + 背包（第二款：红色冲锋衣）。抓壁待机 6、换边抓 6、蓄力 4、跳 6、滑落 6、登顶欢呼 8。左右两侧各一套（帽标不能镜像）。

## 4. 滑雪 SKI（站 6 · 雪坡 · 资源：体温）

### 玩法

竖向往下滑，画面往上滚。

- **UP / DOWN** 左右转（UP 往左、DOWN 往右；按住持续转）。
- **点 OK** 小跳，可以跳过雪包和小树枝。
- 穿过旗门 +1；漏过旗门扣 100 体温。
- 体温每秒消耗 15；撞树扣 250；路边的热可可小屋（滑过去）补 300。
- 越往下坡越陡、旗门越窄。

### 主成绩

通过的旗门数。门槛 10 / 25 / 45。

### 画面（V 模式）

雪地底色 + 树、旗门、雪包。和登山共用雪地图块。

### NABO 动作

滑雪服 + 护目镜（第二款：彩色毛线帽套装，帽子仍是 NABO 的白帽，只换衣服）。直滑循环 6、左倾 4、右倾 4、跳 6、摔倒 8、过终点 6。

## 5. 热气球 SKY（站 7 · 云端 · 资源：热气）

### 玩法

横向飞行，气球固定在屏幕左边 1/3。

- **按住 OK** 加热，气球上升；松开慢慢下降。
- 加热时热气每秒消耗 60；穿过暖风气流（发光的条带）补 200。
- 鸟群和雷云：撞上扣 250。
- 天上飘着邮票（护照主题），碰到 +10 米奖励。
- 越飞越快，障碍越密。

### 主成绩

飞行距离（米）。门槛 200 / 500 / 1000。

### 画面（H 模式）

天空渐变 + 云（图块），只重画气球、云、鸟。

### NABO 动作

飞行帽 + 围巾（围巾要能飘，作为次级动画）（第二款：飞行员皮夹克）。吊篮里待机 6、拉绳加热 6、放气下降 6、被鸟撞 6、接邮票 4。NABO 只露上半身。

## 6. 太空着陆 SPACE（站 8 · 太空 · 资源：燃料）

### 玩法

固定画面，类似 Lunar Lander。着陆器从上面落下，要平稳落到发光的着陆台上。

- **按住 OK** 主推进器喷气（向上减速）。
- **UP / DOWN** 向左 / 向右倾斜（按住持续倾斜），倾斜时喷气会产生横向推力。
- 着陆成功的条件：落在着陆台上、竖直速度和横向速度都小、倾斜不超过 10°。
- 着陆得分 = 100 + 速度越慢加越多（最多 +100）+ 剩余燃料 / 10；然后下一轮从更高处开始、着陆台更小。
- 硬着陆扣 250 燃料并重来这一轮；燃料归零游戏结束。
- 燃料罐偶尔从屏幕边飘过，飞过去补 300。

### 主成绩

累计着陆得分。门槛 300 / 600 / 900。

### 画面（F 模式）

星空背景（程序画的星点）+ 星球地表图块 + 着陆器。喷气火焰用 `ag_glow` 和三角形，不画进素材。

### NABO 动作

宇航服 + 透明球形头盔（罩子里 NABO 照常戴白帽，脸、眼镜、帽标都看得到）。舱内待机 6、喷气 4、着陆 6、硬着陆 8、插旗 8。

## 7. 结局（8 枚金章）

太空站在 8 枚金章都拿到后多一个“回家”选项：NABO 坐火箭俯瞰整张地图，镜头从太空一路滚到小镇。用地图本身 + 硬件竖向滚动做，不需要额外大图。还没设计细节。
