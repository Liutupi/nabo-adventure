# 《NABO 的冒险之旅》美术规格

版本 0.1 · 2026-10-25

本文件是合集**角色和场景**美术的唯一依据；**界面视觉**（风格板、封面、字标、九宫格卡片、护照内页、数字、地图界面元素）的要求在 `UI_DESIGN.md` 第 7 节。所有素材放在 `game-art/adventure/art/` 下，不要修改 `firmware/` 和其他目录。玩法看 `GAMES.md`，按轮次的提示词看 `CODEX_PROMPTS.md`。

## 1. 要做什么

| 包 | 内容 | 优先级 |
|---|---|---|
| 共用包 `shared/` | NABO 基础旅行服 + 地图上的走路、待机、欢呼、失落 | 第一 |
| 地图 `map/` | 9 个世界的装饰图块、9 个站点地标 | 第一 |
| 印章 `stamps/` | 8 枚游戏印章 + 护照亭徽记 | 第一 |
| 资源图标 `icons/` | 7 个资源小图标 | 第一 |
| 界面包 `ui/` | 风格板、封面插画、字标、九宫格部件、护照内页、数字、标签、地图界面元素（见 `UI_DESIGN.md` 第 7 节） | 第一（风格板先行） |
| 各游戏 `games/<id>/` | 该游戏的服装（两款）、动作、场景图块、道具 | 按开发顺序：post → night → climb → ski → sky → space |

## 2. 硬件约束（必须遵守）

- 屏幕 **240×320 竖屏**，RGB565（每通道 5/6/5 位）。大面积细微渐变会出色带：渐变由程序画，素材里不要画大面积渐变。
- 每个动画（一组帧）**不超过 64 色**，索引 0 是透明。边缘可以抗锯齿，打包脚本会把半透明边缘预先和该处的背景色混合。
- 主体必须在实际背景色上一眼认出来（每个世界的底色见 `UI_DESIGN.md` 第 4 节）。
- 引擎会做：水平移动、挤压拉伸、光晕、闪烁、按颜色重新着色印章。**这些不要画进素材。**
- 不能用浮点和大内存：精灵从 Flash 直接逐行解码，所以帧与帧之间尽量只改变需要动的部分。

## 3. NABO

### 3.0 身份（不能改）

- 角色就是 NABO，按你已知的 NABO 形象来做。脸、眼睛、镜框、发型、白帽和帽标、头身比例都以 `nabo-idle.png` 为准，**只有衣服可以换**。
- 帽标上有 NABO 字样，**不能左右镜像**：朝左、朝右的动作要各做一套。只有看不到帽标字样的角度（正背面、深潜那种头朝下的侧面）才允许镜像。
- 画风：平涂 + 两阶赛璐珞阴影，**深色外描边**（用各部位固有色的深色，不要白色贴纸边）。不要软 3D 渲染：缩到 50–60 px 高以后细腻光影都会变成脏色。
- 在目标尺寸、实际背景色上检查：一眼能认出 NABO，能看清表情。太细碎的配饰在小尺寸下会糊，可以简化或去掉。
- 每套服装至少有一个会飘动的部件（围巾、衣摆、背包带之类），作为次级动画来源。

## 4. 地图

### 4.1 装饰图块

地面颜色由程序画渐变（见 `UI_DESIGN.md`）。图块只做点缀，叠在渐变上。

- 32×32 px，每个世界一组 4–8 块，每组 ≤ 16 色，透明背景。
- 世界与内容：深海（海草、气泡、珊瑚）、港口（浪花、木栈道）、小镇（屋顶、路灯、花坛）、铁路平原（铁轨、麦田、电线杆）、夜林（树影、草丛、萤火）、雪山（岩石、雪堆）、雪坡（松树、旗门）、云端（云朵）、太空（星星、小行星）。

## 5. 印章和图标

- **印章**：每个游戏一枚，96×96 px，圆形邮戳风格，中间是该游戏的图形（火车、罐子、山……），外圈留空给引擎写字。只交单色（白色线条 + 透明），铜、银、金由引擎上色。护照亭再做一枚“NABO 冒险护照”徽记。
- **资源图标**：16×16 px，≤ 8 色：氧气、体力、蒸汽、精神、体温、热气、燃料。

## 6. 制作方式：骨骼拼接，不是逐张生成

逐张用图像模型画帧，每帧都会有细微差异，播放会闪会抖。所以 NABO 的所有动作都走**SVG 部件骨骼 + 渲染脚本**（和深潜一样，参考 `game-art/dive/rig/` 与 `game-art/dive/tools/render.py`）：

1. 角色拆成独立 SVG 图层：头（含帽子、头发）、表情（眼睛、嘴可替换）、躯干、飘动部件、左右上臂、左右前臂 + 手、左右大腿、左右小腿 + 脚。
2. 每个部件有固定旋转支点，写在 `art/rig/rig.json`。**头部、脸、帽子的部件全合集共用一份**，服装只换躯干和四肢的部件（皮肤 skin）。
3. 渲染脚本按关键帧和缓动曲线摆姿势导出 PNG，支持 `--anim`、`--skin`、`--facing left|right|front`、`--scale`。
4. 侧面朝向（left / right）的头部要各有一套部件，因为帽标不能镜像。

场景图块、地标、印章、图标可以直接画（它们是静态的），但同样要平涂 + 深色描边。

## 7. 画布、锚点与交付结构

- NABO 每帧 **256×256 RGBA PNG**，透明背景，最终缩到第 3 节的尺寸。
- **锚点固定**：站立类动作对准脚底中心 (128, 224)；半身类对准胸口中心 (128, 160)。同一动作所有帧锚点一致，否则播放会抖。
- 静态素材按目标尺寸 1 倍交付，不要先放大再缩小。

```
game-art/adventure/art/
├── manifest.json                 # 所有动画：帧列表、fps、是否循环、锚点、碰撞框、朝向、服装
├── rig/rig.json  rig/common/  rig/skins/<skin>/
├── frames/<skin>/<anim>/000.png …
├── map/tiles/<world>/*.png   map/landmarks/<station>.png
├── stamps/<station>.png   icons/<resource>.png
├── ui/                           # 界面包，结构见 UI_DESIGN.md 第 7 节
├── games/<id>/tiles/  games/<id>/props/
└── preview/                      # 目标尺寸、实际背景色上的预览拼图（不进固件）
```

`manifest.json` 每个动画至少写：`name`、`skin`、`facing`、`fps`（12 或 24）、`loop`、`frames`、`anchor`、`target_height_px`，以及需要碰撞的动作的 `hitbox`。

## 8. 验收清单

- [ ] 在目标尺寸、实际背景色上一眼认得出 NABO，表情清楚。
- [ ] 脸、眼镜、发型、白帽和帽标与 `nabo-idle.png` 一致；帽标字样没有被镜像。
- [ ] 每个动画 ≤ 64 色（打包脚本会报告）。
- [ ] 循环动画首尾衔接不跳；所有帧锚点一致（拼成 GIF 检查不抖）。
- [ ] 外描边是深色固有色，不是白边；没有画进光晕、拖尾、镜像。
- [ ] 预览拼图放在 `preview/`，不放进 `frames/`。
