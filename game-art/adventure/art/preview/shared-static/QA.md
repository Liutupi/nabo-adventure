## 来源与边界

原生绘图代码与同名 SVG 为本轮创作。主配色来自已选第 3 轮 ① 方案；背景来自固件当前代码并使用 RGB565 量化结果。白印章在浅底使用时必须由 UI 染色，本包包含现有 `UI_BRONZE` 模拟；不同底色的最终对比度仍应在 UI 组合与真机阶段确认。

本轮未修改人物、旧深潜资产、固件、UI 包、主美术清单，也未访问串口。完成的是可供用户审阅和下游组合的静态包；用户是否接受本轮美术、240×320 组合布局与真机观感尚待对应阶段验收。
