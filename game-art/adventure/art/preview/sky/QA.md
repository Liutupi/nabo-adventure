# SKY host art review

The original white NABO ECG/NABO cap remains part of the frozen common head. It is not replaced by the literal flying hat mentioned in the old brief. `sky_a` uses a cream flying jacket/red scarf; `sky_b` uses a brown pilot jacket/teal scarf. Two actual built-in imagegen wardrobe edits are retained as unmodified transparent source PNGs with their prompts, hashes and generator file names. Their generated heads are discarded. Only the unchanged common head/neutral expression and the local original RGB below an alpha-only collar exclusion enter the final rig.

`sky_a` has idle6, heat6, vent6, hit6, receive_stamp4 at 40px half-body, plus settlement_cheer8 at 72px full-body. The light second skin delivers idle6 and settlement_cheer8 as ART_BRIEF allows; other gameplay gestures use the first skin. This is 8 character clips / 50 frames. No frame was individually image-generated. Source pixels are wrapped in independently inspectable SVG layers and masks. These are raster cutouts in SVG containers, not hand-drawn vector characters.

All 40px clips/skins use the same crop, scale, canvas43x40 and anchor22,40. Each skin/height group has one shared palette of 63 visible colors plus transparency. The two full-body cheers share the same 51x72 canvas/anchor27,72; palettes remain independent per skin. Lossless RGBA masters are retained; final 256px frames and target runtime frames are separately quantized directly from masters. Quantization MAE and complete palette are recorded in the manifest. Source alpha below16 is discarded, delivery alpha uses threshold128. These are explicit lossy hardware conversions, not claims of pixel-identical target colors.

Actual source/motion inspection found two concrete defects and repaired them before final output:

1. Rotating the hand carried narrow navy trouser fragments and left cuff pixels on the fixed legs. The hand/forearm mask now keeps original cuff coverage through row160 and original skin pixels below, while trouser pixels stay with the legs. `heat-peak-before.png`, `layers-before.png` and `rope-repair-peak-final.png` retain the visible comparison.
2. The scarf-root color was picked up again by shoulder overlap circles. Source-color exclusions now keep scarf pixels with the collar/scarf rather than the rotating sleeve. Both full-source and final40px heat/vent contacts were inspected after the repair.

Heat and vent use separate deterministic rope clips. Each active grip is computed from the actual source palm and the same skeleton transform as the hand. After target sampling, all 8 active control endpoints land exactly on an opaque skin-colored pixel (0px gap); this is read back from saved PNGs in `verification.json`. Rope starts connect to the burner suspension in the layered scene. Basket back/character/front order hides the cropped lower torso and resting fingertips naturally. No rope crosses or replaces the cap/face.

`same-screen-continuity.gif` shows idle→heat/vent/hit/receive→idle in four simultaneous native240x320 scenes, and the individual scene contacts include every frame. The half-body action first/last runtime PNGs equal neutral idle000 exactly. The crop, scale, head source and character anchor remain constant across every action. Idle uses a small arm breath/scarf sway; hit rotates the whole head/torso together with a damped scarf reaction. The hand/body is intentionally restrained at40px. The white cap, glasses/hair and scarf silhouette remain readable; tiny cap lettering is not expected to be legible at40px and is never mirrored. The neutral original mouth remains unchanged rather than adding a generated facial expression.

Environment/props are native flat-color objects: independent96x96 envelope (program can change brightness), basket front64x28 and back64x10, burner, four32x32 cloud tiles,48x32 thundercloud,16x20 stamp, idle controls, and a distinct4-frame24x20 bird. Ascend/descend movement, glow, fire/flame and stamp flight are program operations. No painted screen gradient or hidden procedural character drawing is included. Runtime scenes use the actual SKY world `#8cc8fa` from firmware WORLD[7].

Production C row decoding was independently compared with indexed source for **77 frames / 3438 rows**. The exact RLE and tables plus estimated C3 descriptors total **60,470 bytes**, below260KiB. This measurement excludes final ELF alignment; these game assets are delivered in their own generated C directory and are not embedded into the user's old factory image. `packing-validation.json` binds the exact manifest and command. `reproducibility.json` records the complete byte-identical rebuild.

All character contacts, source views, full-size peak gestures, layered scene previews and final overview were actually opened with view_image. Source/final identity reuse, alpha, palette, anchors, counts, SVG pixels, looping and gesture endpoints are independently checked. These are host artwork/codec results; no user artwork approval or real-device gameplay acceptance is claimed.
