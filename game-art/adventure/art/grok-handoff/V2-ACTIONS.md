# V2 角色动作 · Grok 任务清单

2026-10-26 用户明确：涉及 NABO 动作的东西放手交给 Grok。规划见 `docs/REDESIGN_V2.md`。

本清单是**待办总表**，不是可以直接发给 Grok 的任务书。每款游戏的 G0 概念、G1 可玩原型经用户认可后，Codex 按下面格式为该款逐个动作建目录、准备输入、写任务书，并告诉用户绝对路径；不要一次把五款全部发出去。

## 每个动作目录的固定结构（沿用 boot-v3）

```
grok-handoff/<GAME>-V2/<编号>-<动作名>/
  README.md        任务书：为什么、输入说明、画幅机位背景、节拍表、交付、边界
  input/01-identity.png        唯一身份原图（SHA256 eecbd9b9…，不许替换）
  input/02-outfit.png          该款 A 款服装设定图
  input/03-start-frame.png     起始人物（身份锁定，透明 PNG，姿态 = 动作第一帧）
  input/04-end-frame.png       需要接回循环或接下一个动作时提供
  input/05-scene-reference.png 横屏 320×240 实际场景与人物比例参考（不要让视频重画背景）
  output/                      Grok 交回：原片 + notes.md
```

## 任务书必须写清

- 动作在游戏里的触发时机和时长（帧数 ÷ 12–15fps）、是否循环、首尾要接哪个动作。
- 机位：横屏侧视或三分之四，固定机位，人物不平移（位移由引擎做），四周留 10% 余量。
- 背景：透明，或全程均匀纯绿 `#00FF00`，无地面阴影和光效。
- 表演：重心、预备、跟随、收势；衣物/挎包/围巾等次级运动；帽标始终正读、不镜像；不要幼儿化夸张。
- 交付：最高质量原片（24fps 以上）、notes.md；不要交抽帧或骨骼。
- 验收（Codex 抽帧后给用户看 GIF）：身份一致、无闪烁变形、首尾能接、实际尺寸能看清脸和帽标。
