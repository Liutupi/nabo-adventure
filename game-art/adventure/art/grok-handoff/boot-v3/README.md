## 画幅、机位、背景

- 6.0秒，一镜到底，固定正面三分之四机位，1024×1024或1080×1080、24fps；保留未裁剪未加字幕的原始视频。
- 人物为大幅半身/上髋裁切，白帽、双手、挎包完整；四周预留约10%活动余量，尤其伸出的手不能越界。不要推拉、摇镜、变焦或整个人横移入场。
- 工牌最终为240×320竖屏，人物将占上部约200px高；头脸与手势需要在小屏仍清楚。Grok交高质量原始视频，不要自行缩到240×320或转低帧率。
- 优先交透明视频；如不支持，背景全程为均匀纯绿`#00FF00`，没有地面、投影、渐变、绿光反射或背景纹理。深蓝封面背景、罗盘、标题和按键由Codex后期分层合成。
- 帽标和字母始终正读，不能镜像；不要让帽子、眼镜、发丝和手指跨帧变形或忽隐忽现。

## 一段连续的动作节拍

动作要有重心、预备、跟随和停顿，不能把头、前臂、手掌当成几个硬片轮流旋转。动作幅度克制，情绪有感染力，避免幼儿式大幅摇头蹦跳。

| 时间 | 表演 |
|---|---|
| 0.0–0.8s | 从起始图自然接上：温和看向用户，一次轻眨眼、呼吸和很小的前倾；伸出的手略收回，肩膀先动、衣料与挎包稍后跟随。 |
| 0.8–1.4s | 顺势做一次短促自然的招呼/小挥手，视线仍与用户交流。另一只手自然扶着包带，不能僵住成支架。 |
| 1.4–4.1s | 配合现有“NABO,陪你冒险”的节奏，表情由注意到微笑，嘴部轻微自然说话即可；招呼手展开成邀请，肩、肘、腕依次带出，末端有柔和收势。不要添加新的音轨。 |
| 4.1–5.3s | 很轻地朝旅途方向看一眼，再回看用户；包带和衣袖有小幅跟随，保持欢迎感。 |
| 5.3–6.0s | 回到与封面相配的开放邀请姿态，收稳至少0.5秒，方便固件停留最后一帧。不是循环，不要突然复位。 |

语音会由固件在开场1.4秒时播放，结束于4.090625秒左右。优先保证人物自然，口型不用逐音素硬对；不要为了口型改变NABO的脸。
