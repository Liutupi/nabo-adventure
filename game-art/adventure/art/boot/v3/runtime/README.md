# BOOT-V3-01 固件候选

Grok原片145帧/24fps，固定机位、原白帽与正读帽标。每隔一帧取样，73帧在固件按整数12fps播放，约6秒，随后保持最终姿态。MPEG1头的24fps只满足编码语法，固件不使用其播放时钟。片中没有音轨；另用已验收的原WAV，在1400ms开始、4090.625ms结束。扬声器按用户要求保持关闭，实体听感不在本轮验收内。

`boot-welcome.m1v`是208×272、I/P-only的完整主视觉，行合成时整数双线性还原到240×320；口号和OK提示由原生12px字库叠加。`cover-poster.m1v`供返回封面直接显示终态；开机本身保持动画的实际末帧，不切换海报、不跳回首帧。所有原始图和Grok视频保留。

用`tools/prepare_boot_video.py --ffmpeg <FFmpeg7.1绝对路径> --output <空候选目录>`独立复现，输出不得覆盖已验收bin。脚本固定抠图阈值、整段同一裁切、位置、比例与编码参数，禁止逐帧拉动或骨骼重演。`reproduction.json`记录本次实际运行及输出哈希。由`tools/generate_boot_video.py`核对选择、音轨、片数、尺寸、来源和SHA后生成C数组；换选择后另跑全部门禁和真机。

V3使用224KiB的开机与全UI合计预算，实际226,733B。增加64KiB来自原旧字库未使用字形的无损精简，原字形像素/间距不变；352KiB app保留额不变。旧RLE开机的160KiB门禁和其它游戏的260KiB门禁保留。两份208×272 YCbCr引用图共169,728B，按封面生命周期分配/释放，无RGB整屏缓冲、无每帧堆分配。设备解码速度与实际最低堆必须另测，不能用宿主速度推断。
