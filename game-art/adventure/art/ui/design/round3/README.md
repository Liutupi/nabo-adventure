## 后续开机、封面和字标要求

用户要求沿用此前系列的开机呈现：已选①旅行服的 NABO 形象，配合声画文案 **“NABO,陪你冒险”**。这项要求已为后续第 5 轮封面、标题字标和开机演出记录，当前四屏没有改成启动屏，也没有假称音频或开机动画已完成。既有系列的音画与声音来源由主任务复核后使用。

- 方向①承接：米黄票纸、深蓝墨、邮戳红的开机界面，主角为同一 NABO，文案与配音均为“NABO,陪你冒险”。
- 方向②承接：明亮贴纸 UI 的开机界面，贴纸白边只用于 UI，同一 NABO 不加白描边，文案与配音均为“NABO,陪你冒险”。
- 方向③承接：深蓝星图、金线的开机界面，主角为同一 NABO，文案与配音均为“NABO,陪你冒险”。

正式开机动作、时长与音源确认属于后续制作，尚未由本轮决定；不会因为选 UI 方向而重设计 NABO 身份。

`palette.json` 是颜色角色映射，`palette.png` 是色卡，`layout.json` 保存各屏真实文案、字号、文字实际边界和人物摆放位置。文字直接使用已验证的 SourceHanSansCN-Medium.otf 在 12 / 16 / 18 px 栅格化，再以单色字模写入调色板，不含生成的假文字、渐变或纸张噪点。顶栏 y=0..31，底栏 y=290..319；重要卡片文案留至少 8 px 内边距。

人物来源为用户选定的第 1 轮 v2①轻便徒步，由 `art/frames/travel/masters/idle/000.png` 无损母版裁去透明画布后等比缩至 48 / 56 / 72 px，保留采样 RGB，使用同一套 63 个可见色加透明索引。未使用旧深潜 SVG，也没有用程序重画脸、眼镜、帽子或身体。标题与结算暂用这张已确认来源的待机姿势表示人物位置，正式欢呼动作属于后续轮次；没有冒称欢呼动画已完成。

画面数值是**设计示例**：地图/护照展示跳一跳最佳 12、1 枚铜章；POST 标题示例尚无纪录；结算示例 12 分、银章、距离金章 13。它们是独立状态效果图，没有读取或改写设备成绩。POST 使用正式设计门槛 5 / 12 / 25，未替换当前固件占位关卡的临时门槛。

字体 SHA256：`a94e558a2fe972bee4f46bce0843abff37063fd68c33f1e7d9058f6f09432b01`，已对照 `firmware/tools/collection-fonts.json`。默认从本机 `nabo-fortune/tools/fonts/SourceHanSansCN-Medium.otf` 读取；可通过 `--font` 指定同哈希文件，找不到或不匹配会停止，不会替换为其他字体。
