## 一局流程（约 2 分钟）

| 段 | 高度 | 交互 |
|---|---|---|
| 点火 | 0 | 指针在仪表上来回摆，中键按在绿区点亮 3 台发动机，越准起飞越快 |
| 发射升空 | 0–12 km | 左右躲鸟群/飞机/气球；雷暴云先虚线预警再劈闪电；侧风推人；屏边红箭头预告横穿物 |
| 一级分离 | 12 km | 指针扫过，绿区按中键：完美补 30000 燃料并提速，错过只补 6000 且减速 |
| 冲出大气层 | 12–100 km | 极光环（穿过加分降温）、高空急流、流星；加速过多会过热掉船体 |
| 太空 | 100–2000 km | 卫星、太空垃圾、小行星；之后跟节拍按 3 下做地月转移点火 |
| 奔月 | → 38 万 km | 流星雨、彗星、月球越来越大 |
| 登月 | 月面 | 登月舱分离：点按中键反推、左右对准着陆台，慢落成功 → NABO 出舱插旗 |

贯穿全程：燃料一直在耗，船体 3 格；中键加速更快、护盾能撞碎鸟/气球/太空垃圾，但费燃料、在大气层里升温；星星、燃料罐、修理包；擦着障碍飞过加分；连击叠倍率。

## 键位（横拿，左→右）

左 = 按住左移；中 = 点按加速 / 关键时刻按 / 登月反推，**长按暂停**；右 = 按住右移（游戏中不回地图）。暂停页：中继续、左重来、双击上回地图。与 NIGHT/SKI 一致。

## 平衡（机器人，60 种子）

不按 37 秒（自动点火后被撞毁）；狂按 7 秒（加速过热）；普通 60 秒，13% 登月；熟练 82 秒，62% 登月、中位约 5600 分。门槛暂拟 铜 1500 / 银 3500 / 金 6000（登月成功约 +1000–2500）。

## 固件代价（G4 前要定）

背景图按现在的尺寸和调色板估算约 120–160 KB（几张整幅背景占大头），当前扣保留额后只剩约 51 KB；接入时需要动用部分 352 KiB 保留额，或缩小背景（降色数/裁窄后平铺）。V1 太空的人物帧继续沿用，不额外占空间。
