# SPACE V2「月面跳跳」· G0 概念 + G1 试玩原型

2026-10-26 14:44 用户“好的，继续”。按 REDESIGN_V2 顺序做 SPACE。V1（竖屏固定画面、一轮一个着陆区）仍在固件里，用户认可 V2 之前不动。

**素材原则**：现有素材够用就不交 Grok。已有着陆器前后两层（NABO 在头盔舱里）、舱内待机/喷射/着陆/硬着陆/插旗/结算动作、着陆台、旗、燃料罐、陨石。着陆器不能旋转、尺寸大（96 px），所以 V2 不做“倾斜着陆”，改成**横向卷动的月面跳站**：主引擎点按、左右侧喷。月面、着陆台灯条、火焰是程序画的。

- 试玩页：`prototype/space_v2.html`；单文件版 `python tools/build_space_v2_artifact.py`（输出到 `private/`）。
- 规则：`prototype/adv_space_v2.js`（整数 60 Hz + mulberry32；月面地形用无状态整数哈希，C 同一算法即可复现）。画面：`prototype/adv_space_v2_draw.js`。

## 30 秒里发生什么

横拿。NABO 坐在宽着陆台上，点按中键起飞，一下一下地喷（像拍皮球）控制高度；按住左右键侧喷往右飞，越过山脊，找到下一个着陆台，慢慢落、两只脚都在台上才算成功：加分、加燃料、NABO 下舱插旗。燃料一直在耗，喷气更耗。宽台 ×1 最安全，窄台 ×2/×3 常在山脊上、补的燃料少；连续着陆不摔叠倍率。路上漂着燃料罐。每 25 秒一个事件：流星雨（顶上先出感叹号）、太阳风（一直往右推）、低重力、月夜（只看得清身边）。

## 键位（横拿，左→右）

| 键 | 游戏中 | 暂停页 |
|---|---|---|
| 左 = OK | 按住左喷 | 重来 |
| 中 = 下 | **点按**主引擎；**长按暂停** | 继续 |
| 右 = 上 | 按住右喷（游戏中不回地图） | **双击**回地图 |

与 NIGHT/SKI V2 一致。主引擎改为点按（V1 是按住），正是为了让“长按中键暂停”不和喷气冲突。

## 对照深潜

| 深潜 | 月面跳跳 |
|---|---|
| 氧气一直掉 | 燃料一直掉，喷气更快 |
| 每秒决定转不转向 | 每秒决定喷不喷、往哪边推 |
| 贪气泡要贴近危险 | 窄台 ×3 在山脊上、燃料罐在半空，贪就容易摔 |

## 当前数值（等试玩后调）

重力 6、低重力 3（Q8 px/帧²），每下主引擎 −200、侧喷 5/帧；燃料 0–100000，开局 70000，每帧耗 13，每喷一下 700，侧喷 30/帧，摔一次 16000，燃料罐 12000。安全着陆竖速 ≤300、横速 ≤170，≤120 算完美 +50。着陆分 =（100×台倍率 + 完美 50）×（1 + 连续/2，最多 ×5）。台：宽 110 px ×1 补 30000，中 84 px ×2 补 25000，窄 68 px ×3 补 20000。

机器人（40 种子）：不按 65 秒 0 分（坐在台上等燃料耗光，流星会砸）；乱喷 14 秒；普通 176 秒 / 中位约 5700 分；熟练 220 秒 / 中位约 7500 分。门槛暂拟 铜 1000 / 银 4000 / 金 10000。
