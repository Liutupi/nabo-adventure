# 登山 CLIMB 正式玩法

2026-10-26 · 站 5 · 雪山 · 资源：体力。规则标准答案是 `prototype/adv_climb.js`，C 版 `firmware/main/adv_climb.c` 与它逐步对拍。

## 一句话

竖拿工牌，NABO 抓在左右两面岩壁之间往上爬：**点 OK 换到对面岩点上 1 米，按住 OK 蓄力、松开在同侧跳 2/3 米**。读清楚上面哪边有岩点、躲开落石，体力耗尽结束，成绩是到过的最高海拔（米）。

## 按键（240×320 竖屏）

| 键 | 进行中 |
|---|---|
| OK 点按（按下到松开 < 12 帧，0.2 秒） | 换边：目标 = 上 1 行、对面墙 |
| OK 按住再松开 | 跳：同侧墙；按住 12–39 帧跳 2 行，≥ 40 帧（约 0.67 秒）跳 3 行 |
| 上键长按 | 暂停（外壳统一规则）；暂停中 OK 继续、下键重来 |
| 上键双击 | 任意阶段回地图（外壳统一规则） |
| 上键单击、下键 | 进行中不做任何事 |

判定以**松开**那一步为准（OK 按下时开始计时，松开才知道是点还是蓄力）。动作进行中按下/松开的意图会排进一个槽，当前动作结束立刻执行，后来的覆盖先前的。上键不参与攀爬，所以与双击返回无冲突。

## 规则（60 Hz 整数）

- 每行 1 米，40 px。每行左右各可能有一个岩点：普通、碎石、结冰。行数据存在 32 行环形缓冲里（每行 1 字节：两侧岩点类型各 2 位，两侧水壶各 1 位），始终生成到 NABO 上方 12 行。
- 目标处没有岩点：滑落一行，**扣 100 体力**。目标有岩点：换边 24 帧、跳 30 帧，落定时才算到达。
- 体力 1000 起，每秒消耗 30（停在结冰岩点上 60）；**每到达一个新的最高行补 20**（回爬旧高度不补）；水壶补 250。
- 碎石：抓上后 60 帧（1 秒）塌落，NABO 滑落一行；岩点永久消失。
- 落石：海拔 ≥ 8 米开始，每 `max(120, 300 − 海拔×3/5)` + 0–60 帧一块，60% 落在 NABO 当前一侧。生成在 NABO 上方 9 行处，每帧下落 3 px（约 2 秒到达），屏幕外时顶部亮红色“!”。砸中扣 250、取消当前动作并滑落一行，之后 60 帧无敌。换边动作前半程算原侧、后半程算目标侧。
- 滑落：先找下一行同侧，再找对侧，最多向下 3 行；不会低于环形缓冲保留的底部。滑落 30 帧，不扣额外体力（被砸、踩空自身已扣）。
- 每过 50 米的整数倍播放一次登顶欢呼（48 帧，只在空闲时显示，任何动作立即取消）。
- 体力 ≤ 0 结束，`over` 置位，外壳进入结束动画再到结算。主成绩 = 最高行（米），上限按 `uint32`。

### 生成

- 0–4 行两侧都是普通岩点（新手阶梯）。之后每行以 `max(25, 50 − 行/6)`% 概率两侧都有，否则随机一侧。
- 类型：碎石 `行<12 ? 0 : min(22, 4+行/12)`%，结冰 `行<80 ? 0 : min(25, 5+(行−80)/10)`%，其余普通。
- **可达性保证**：生成第 k 行后检查第 k−3 行的每个岩点，若它的三个去向（上 1 对侧、上 2 同侧、上 3 同侧）都没有“不会碎”的岩点，就把第 k 行同侧设为普通岩点。因此任何位置都至少有一个不靠碎石的出路；踩空只因读错墙或按错时长。
- 水壶：第 20 行以后每 24–36 行放一个，挂在该行不会碎的岩点上。

## 平衡（`node tests/climb_policy.js`，200 种子）

策略只用屏幕可见的信息、按真实按键时长操作：

| 策略 | ≥50 铜 | ≥150 银 | ≥300 金 | 中位 |
|---|---|---|---|---|
| 不按 | 0 | 0 | 0 | 0 |
| 只会点（盲换边） | 0 | 0 | 0 | 3 |
| 只会跳 2（盲跳） | 极少 | 0 | 0 | ~20 |
| 普通（读墙，反应慢 0.25–0.55 秒） | 约 97% | 约 30% | 0 | ~120 |
| 熟练（读墙，0.1–0.25 秒，会躲石头、找水壶） | 约 98% | 约 70% | 约 7% | ~190 |

盲按拿不到铜章；铜章要读墙，银章要躲落石，金章要求长时间不失误。门槛沿用 50 / 150 / 300。

## 画面

- 竖屏 240×320；顶部 32 px 深色条：“雪山”、体力条（< 250 变红）、海拔 `NNNm`。底部 20 px 提示条。
- 镜头锁在 NABO 的手：NABO 抓点的屏幕 y 固定为 230（根点 271），世界随 `handY` 滚动；动作期间 `handY` 线性插值，所以画面平滑。
- 两侧 32 px 岩壁用 32×32 图块（海拔 <100 灰、100–199 冷、≥200 雪），中间为纯色崖缝。岩点锚在 x=33 / 207，水壶挂在墙内侧 x=18 / 222。
- 落石在 NABO 那一列（根点 x 56 / 184）下落。
- 正式 A 款登山服原尺寸动作：抓壁待机、换边（按逐帧手部接触点把根点从左墙移到右墙）、蓄力（按蓄力进度 4 帧）、跳、滑落、登顶欢呼，结算用正面欢呼。B 款红色冲锋衣素材随包嵌入，但选择系统未接线，不能宣称可用。

## 验证边界

宿主：JS/C 逐步对拍（idle / skilled / casual / tapper / lazy / fuzz）、外壳轨迹 `climb_round`、规则变异、生产 C 画面截图与增量=整屏。**尚未真机**：按键手感（点按与蓄力的 12 帧界线）、帧率、声音、10 轮进出、睡醒都需要实体验收。
