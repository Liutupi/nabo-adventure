# NABO 的冒险之旅 v0.1.0 · 首个公开预览固件

AI Passport 上的离线冒险游戏合集：从小镇、深海、铁路、夜林，到雪山、云端和月球，收集八站印章，填满冒险护照。

- 八款游戏：跳一跳、深潜、小火车送信、萤火虫之夜、登山、雪崩速降、热气球、火箭登月。
- 萤火虫、雪崩速降、火箭登月为横屏V2；火箭有点火、分离、奔月和反推着陆完整流程。
- Grok制作的NABO开机演出，配合“NABO,陪你冒险”语音；独立主题A款服装、护照印章、成绩保存和自动休眠。
- 无需联网、激活或小智服务。

## 下载

- **首次安装**：`nabo-adventure-v0.1.0-full.bin`，从0x0刷入；会清除原设置与成绩。
- **保留数据升级**：`nabo-adventure-v0.1.0-app.bin`，使用ZIP内保护式工具，只写0x10000。
- **完整工具包**：`nabo-adventure-v0.1.0.zip`，含镜像、安装/按键说明、许可、校验和及升级工具。

[安装说明](https://github.com/Liutupi/nabo-adventure/blob/v0.1.0/docs/INSTALL_v0.1.0.md)。全部素材嵌入应用，无需另刷assets.bin。
