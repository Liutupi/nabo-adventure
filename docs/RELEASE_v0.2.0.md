# NABO 的冒险之旅 v0.2.0 · 三款新玩法与统一界面

八站离线游戏合集的新预览版，适用于 FoloToy AI Passport ESP32-C3 / 8MB。

- **邮政快车**：加速与刹车、对准吊架投递/补充邮袋，留意限速桥、红灯和动物。
- **双线攀岩**：左右手交替抓点，换线避开断点和落石；冰点要按住，碎石不能久停。
- **风层邮差**：选择四层风向，加热/放气控制高度，提前投信，躲开树、鸟和雷云。
- 六款横屏游戏统一标题、倒数、暂停和结算卡片；新增滚动分数、印章和下一枚章的距离。
- 跳一跳新增渐变背景、蓄力条、连中提示与结算章；深潜结算加章。萤火虫灯光衰减、滑雪旗门横移进一步打磨。
- 攀岩岩壁和热气球背景使用可释放的无损缓存，退出后回收；全部素材仍嵌入应用，无需联网或另刷资源。

## 下载和升级

- 首次安装：`nabo-adventure-v0.2.0-full.bin`，从 **0x0** 写入，**会重置设置与成绩**。
- 保留存档升级：`nabo-adventure-v0.2.0-app.bin`，在兼容分区上只写 **0x10000**；ZIP 内提供身份、分区和读回校验工具，可选择无需备份旧固件的升级方式。
- 完整工具包：`nabo-adventure-v0.2.0.zip`，包含镜像、安装/操作说明、许可与校验和。

[安装说明](https://github.com/Liutupi/nabo-adventure/blob/v0.2.0/docs/INSTALL_v0.2.0.md)。从 v0.1.0 升级时，POST/CLIMB/SKY 的旧成绩键保留，旧章和解锁继承；三款 V2 分数单位不同，使用独立成绩键，从新纪录开始。其余成绩和设置沿用原键。
