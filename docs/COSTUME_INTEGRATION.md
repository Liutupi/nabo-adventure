# 各关服装与接入边界

2026-10-25 用户再次明确：每关应有符合玩法的独立服装，不能全程沿用同一套旅行服。按实际素材与程序分别核对，不能把素材齐全说成游戏已经接入。

轻便徒步装用于开机、地图、护照亭等合集页面。游戏原则上使用独立服装；2026-10-26 用户认可 NIGHT V2 原型并明确现有素材够用，因此该款使用旅行步行帧和挑杆罐子，原睡衣坐姿素材保留但不再打包。NABO的脸、眼镜、白帽和帽标保持身份一致。主题服装须在轮廓、装束和道具上有区别，不能只把同一件衣服换颜色。

|---|---|---|
| 小火车 POST | 蓝色背带工作服、衬衫，坐在车头窗内 | `post_a/post_b`素材齐；当前已接A款；B款标题切换尚未接线 |
| 萤火虫 NIGHT V2 | 徒步旅行装、挑杆玻璃罐 | 用户认可共用 `travel/walk_right/sad/cheer`；旧睡衣A/B源文件保留，不嵌入当前应用；V1验收不沿用到V2 |

**2026-10-26 起 B 款素材默认不打包进固件**（`tools/build_adventure_assets.py --include-b-skins` 才打包），因为切换系统未实现且全部 B 款约 118 KB 超出容量；实现切换时须先解决容量。NIGHT V2另有上述共用旅行帧的明确例外，其余独立A款已接入。

已实际查看六款A服装的生产源帧，并核对各自manifest的A/B皮肤。B款按原设计银章解锁，标题页选择并以`adv_skin_<id>`保存；共用切换/存档系统目前仍待实现。不能在未接线前宣称银章换装可用。旧跳一跳、深潜继续保留各自既有造型与玩法，不改成通用旅行服。

服装动作及正式资源包仍须逐款接入、宿主像素检查和实体效果验收；白帽与帽标不能镜像。身份原图、完整动作与两款设计见`../game-art/adventure/ART_BRIEF.md`和各游戏manifest。
