# 统一游戏返回操作

2026-10-25 用户要求所有游戏统一返回地图，采用双击上键。此规则覆盖跳一跳、深潜、小火车、NIGHT和其余四款的共用外壳；八款正式引擎现已接入，实体新游戏手感仍待验证。

## 新四款速查（竖拿工牌）

上/下/OK均指屏幕右侧的实体键。所有阶段两次短点上键回地图，进行中的单击或长按上键不会退出。

| 游戏 | 主要操作 | 暂停 | 结束与成绩 |
|---|---|---|---|
| 登山 CLIMB | 点OK换到对面岩点上1米；按住OK松开在同侧跳2/3米。看准岩点，水壶补体力，落石要躲 | 长按上 | 体力耗尽结束，记最高米数；50/150/300米为铜/银/金 |
| 滑雪 SKI | 按住上向左、按住下向右；点OK跳过雪包，穿旗门加分，热可可补体温 | 长按OK | 体温耗尽结束，记通过旗门数；10/25/45门为铜/银/金 |
| 热气球 SKY | 按住OK加热上升，松开下降；躲鸟和雷云，暖风补热气，邮票加距离，别撞树梢 | 长按上 | 热气耗尽结束，记距离；200/500/1000米为铜/银/金 |
| 太空 SPACE | 按住OK减速下降；按住上/下侧推左右，慢而平稳地落入着陆区 | 两次短点下 | 燃料耗尽结束；着陆得分，300/600/900分为铜/银/金 |

标题页OK开始；暂停中OK继续、下键重来。SPACE的侧推长按不计入双击暂停，NIGHT/SKI/SPACE的移动长按不计入双击返回。

| 操作 | 行为 |
|---|---|
| 双击上键 | 从任意游戏阶段回地图；包括标题、倒数、进行中、暂停、结束动画、结算、局内练习 |
| 单击上键 | 保留该游戏操作；POST选上轨，深潜暂停/继续或结算回游戏标题；跳一跳不退出 |
| 长按上键 | POST等保留暂停；NIGHT是按住右移，不暂停、不退出。NIGHT长按中DOWN暂停。旧游戏不会因此回地图 |
| 菜单页的返回 | 保留现有操作；地图、护照、设置等不属于本次游戏按键改动范围 |

应用层的`adv_game_map_key()`为共用入口：旧游戏在平台路由中先识别，外壳游戏在统一会话处理时识别。不是给每款游戏另写一套返回规则。BSP按键引脚和时间参数保持不变。

NIGHT横拿后三键朝下：左OK/右UP按住连续移动，中DOWN短点举罐、长按暂停。只有两次短点UP才返回；移动长按不能掺入双击。99e71e9f用户已实测上述移动、暂停和返回全部正常。

已结束的局如果在结束动画期间双击返回，先处理该局纪录再释放状态，避免跳过结算丢掉已完成成绩。进行中提前退出沿用原有未完成局规则。练习和自动测试不会写入真实成绩或伪造解锁。

标题/暂停/结算及跳一跳底栏、深潜标题/暂停/结算均显示“双击上回地图”。POST仍为320×240横屏；回地图恢复240×320。蓄力音沿用用户已确认的代码和原PCM。

JS原型先改、重新录制11条外壳轨迹后再移植C。新增轨迹覆盖六个外壳游戏的全部六个阶段、两个旧游戏入口和结束动画提前返回时的正常保存/测试抑制；新增故意改坏返回键的变异检查。183项宿主检查与IDF构建通过；实际刷写与实体确认见`VALIDATION.md`。

2026-10-26 云端：SKI 按住上/下转弯、长按 OK 暂停；SPACE 按住上/下侧推、两次短点下暂停；两款都与 NIGHT 一样只认两次短点上回地图。SKY 沿用长按上暂停、双击上返回。见 `game-art/adventure/LATE_GAMES_DESIGN.md`，未上机验证。

## 2026-10-26 NIGHT V2（用户已同意 REDESIGN_V2 第 7 节）

NIGHT V2 横拿：左键按住慢走、右键按住小跑、中键点按挥罐（能量满时双击放光）。**游戏中任何上键手势都不回地图**；长按中键暂停，暂停页里中键继续、左键重来、**双击上键回地图**。标题/结算页双击上键照旧回地图。上面 2026-10-25 的 NIGHT“两次短点上返回”只适用于 V1，已被替代。详见 `game-art/adventure/NIGHT_DESIGN.md`。
