# NABO 的冒险之旅 v0.3.0 · 八款双人对战

八站离线游戏合集的新预览版，适用于 FoloToy AI Passport ESP32-C3 / 8MB。这一版的主角是**双人对战**：两块工牌用 ESP-NOW 直连，不需要路由器、配网或手机。

- **八款都能对战**：护照亭 → 双人对战 → 选游戏 → 大厅。附近打开对战的工牌会自动出现（NABO-xxxx），一方邀请、一方接受，倒数 3 秒同时开始。被邀请的人会跟着切到邀请者选的游戏。
- **同一张图**：双方用同一个随机种子，赛道、障碍、时刻表完全一样，各玩各的，比分数（深潜比深度）。
- **先结束不等于输**：一方先结束，另一方只要超过他的分就立刻赢；没超过就结束则输，打平算平局。两边屏幕底部用红字写明“要超过多少”。
- **和 NABO 练习**：只有一块工牌也能玩。跳一跳是 NABO 真的在跳；其他七款是按本关铜章到金章分数推进的“影子对手”。
- 对战不计成绩、不盖章，结算页 OK 再来一局、下键回大厅；断线或对手退出，本局不算。
- 横屏六款里上键（右键）是操作键，退出对战改为**长按下键**；竖屏的跳一跳/深潜双击上键退出。

## 下载和升级

- 首次安装：`nabo-adventure-v0.3.0-full.bin`，从 **0x0** 写入，**会重置设置与成绩**。
- 已用 v0.2.0 完整镜像装过（新布局）：`nabo-adventure-v0.3.0-app.bin` + ZIP 内 `tools/flash_candidate.py` 保留存档升级。
- 还是旧 2MB 布局：ZIP 内 `tools/install_keep_saves.py` 先整片备份，再只写分区表和应用，**不碰存档**。
- [安装说明](https://github.com/Liutupi/nabo-adventure/blob/v0.3.0/docs/INSTALL_v0.3.0.md)
