# NABO 冒险之旅 · 八站离线游戏

## 玩法介绍

把工牌变成一本可以玩的冒险护照，跟着 NABO，从深海一路走到月球。

跳过小镇的平台，潜入蓝色深海，开着小火车送信；夜里追逐萤火虫，在雪崩前滑下山坡，再点燃火箭、飞向月球。八款离线小游戏连成一张冒险地图，铜、银、金三种印章，把每次挑战留在护照里。

【八站旅程，一站一种小挑战】
• 跳一跳：按住蓄力、松开起跳，找准下一块平台的距离。
• 深潜：换向与俯冲，穿过海里的障碍，守住氧气，挑战更深纪录。
• 小火车送信：看提示选轨，车站靠近车头时轻点 OK 送信，按住 OK 鸣笛赶开牲畜，沿途捡煤补蒸汽。
• 萤火虫之夜：罐子的光就是体力。慢走、小跑、挥罐捕捉，金萤火虫带来惊喜，飞蛾和猫头鹰也会添乱。
• 登山：读清岩点，点按换边、蓄力跳高，躲落石、接水壶。
• 雪崩速降：左右转弯穿旗门，冲上跳台后空中转体，用连击和速度把雪崩甩远。
• 热气球：按住加热、松开下降，避开鸟群和雷云，在暖风里继续向前。
• 火箭登月：看准绿区点火、一级分离、地月转移，再用反推把登月舱稳稳放到着陆台，迎接插旗演出。

【把成绩，盖成自己的旅程】
从跳一跳开始，拿到上一站铜章后解锁下一站；八款游戏共24枚铜、银、金印章。护照记录最佳成绩和已获得的印章，已解锁的站点可以反复挑战，随时回来继续。

开机有 NABO 的欢迎演出和“NABO，陪你冒险”语音；地图、护照和各关保留统一的角色身份。固件独立离线运行，无需配网、激活或小智服务。可调整音量、亮度、扬声器和自动休眠。

v0.1.0 是首个公开预览版。萤火虫、雪崩速降、火箭登月已接入横屏V2；登山和热气球目前保留V1，后续再重做。B款换装选择尚未开放。三款新玩法的实体手感、读图及本轮声音仍欢迎反馈；界面示例含演示数据，封面为AI宣传插画，均非实物摄影。

项目与 FoloToy 官方无隶属或背书关系。源码与美术许可见仓库 NOTICE。

## 使用说明

一、安装与存档

本页面提供 v0.1.0 完整安装镜像，适配 ESP32-C3 / 8MB 的 AI Passport。完整安装从0x0写入，会重置原设置和成绩；如要保留数据，请先看 GitHub 的应用升级说明，使用保护式工具只更新0x10000应用区。所有素材都已嵌入，无需另外安装资源包。

空存档首次完整安装尚未真机验收；本轮实物检查采用保留旧分区的应用升级。已完成自动流程、存档比对和设置页临时30秒睡醒检查，不能替代每款游戏的完整实体试玩。

二、从地图出发

竖拿工牌，上/下键沿地图移动，OK进入站点；长按OK打开护照，地图上长按上键回封面。跳一跳起步，依次解锁深潜→小火车→萤火虫之夜→登山→雪崩速降→热气球→火箭登月。地图上可先看到下一个锁住的站点，铜章达到后即可进入。

铜章门槛：跳一跳10分、深潜100米、小火车5封、萤火虫100分、登山50米、雪崩速降300分、热气球200米、火箭登月1500分。银、金章继续提高挑战目标。

三、三款V2横屏操作

萤火虫之夜、雪崩速降、火箭登月请顺时针横拿，三键朝下：左边是原OK键，中间是原下键，右边是原上键。中键开始/重玩；长按中键暂停，暂停后中键继续、左键重来、双击右键回地图。标题、暂停、结算页可双击右键返回；进行中右键负责移动。

• 萤火虫之夜：左键按住慢走，右键按住小跑，中键点按挥罐；能量满时双击中键放光。抓到萤火虫补光，挥空或碰到危险会损失光；看准虫群高度再出手，遇树根别一直跑。光耗尽，本局结束。
• 雪崩速降：左右键按住转弯，中键点按跳跃；从跳台起飞后在空中点中键转体。直滑较快，转弯会掉速；连续穿旗门能提速，漏门或撞树会让雪崩靠近。雪崩追上，本局结束。
• 火箭登月：左右键按住移动，中键在点火/分离的绿区按下；飞行中点按加速，地月转移跟着光圈节奏按，接近月面时点按反推减速并对准平台。燃料耗尽或船体归零会失败；在平台上慢而稳地落下则完成登月，接续出舱插旗演出。加速会消耗燃料，别一直狂按。

四、其余五款操作与结束条件

• 跳一跳（竖屏）：按住OK蓄力，松开起跳；下键切换角色，长按下键重新开始。落空结束，记录本局分数。双击上键回地图。
• 深潜（竖屏）：OK开始/换向，下键按住俯冲，上键点按暂停/继续。躲开障碍、留意氧气；氧气耗尽结束，记录最佳深度。双击上键回地图。
• 小火车（横屏）：上/下键按屏幕提示预选轨道，车头靠近同色车站时轻点OK并松开送信；按住OK鸣笛。先玩练习：选上轨→送红信→按住鸣笛。正式局靠捡煤补蒸汽，蒸汽归零结束，成绩是送达封数。长按上键暂停，双击上键回地图。
• 登山（竖屏，V1）：点按OK换到对面的上一层岩点；按住OK蓄力再松开，在同侧跳2层或3层。看岩点、躲落石、接水壶，体力耗尽结束，成绩是最高米数。长按上键暂停，双击上键回地图。
• 热气球（竖屏，V1）：按住OK加热上升，松开下降；避开树梢、鸟群和雷云，接暖风补热气、收邮票增距离。热气归零结束，记录最远距离。长按上键暂停，双击上键回地图。

五、日常使用与反馈

正常结束一局后，最佳纪录和印章会保存；练习及自动测试不写真实成绩。到护照亭进入设置，可调音量、亮度、扬声器与休眠。保存的默认休眠间隔为300秒，无操作后熄屏，按上键唤醒；首次安装默认声音设置以设备实际显示为准。
