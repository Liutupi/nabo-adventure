一、安装与开始

本页面提供与 GitHub v0.2.0 相同的完整安装包。点击社区“安装最新版”进行完整安装，会重置原设置与游戏成绩。如要保留存档，请改用 GitHub 的应用升级说明，不要用完整安装包覆盖存档。全部素材已包含，不用另装资源，也不用配网或激活。

下载及保留存档升级：
https://github.com/Liutupi/nabo-adventure/releases/tag/v0.2.0
https://github.com/Liutupi/nabo-adventure/blob/v0.2.0/docs/INSTALL_v0.2.0.md

开机后按OK从封面出发。竖拿工牌，上/下沿地图移动，OK进入站点；长按OK打开护照，在地图长按上键回封面。选择护照亭可进入设置。

二、沿地图解锁

从跳一跳开始，依次走向：深潜→小火车（邮政快车）→萤火虫→登山（双线攀岩）→滑雪（雪崩速降）→热气球（风层邮差）→火箭登月。拿到上一站铜章，才能进入下一站。

铜章目标：跳一跳10分；深潜100米；邮政快车150分；萤火虫100分；双线攀岩80分；雪崩速降300分；风层邮差300分；火箭登月1500分。银、金章继续提高挑战目标。

保留存档升级时，POST/CLIMB/SKY旧成绩与已获章继续保留，三款新玩法按新分数重新记录最佳成绩，其余记录沿用。社区完整安装会重置全部进度。

三、六款横屏游戏

从小火车开始的六款游戏请顺时针横拿、三键朝下：左为原OK键，中为原下键，右为原上键。中键开始；长按中键暂停，暂停后中键继续、左键重来、双击右键回地图。标题和结算页也可双击右键返回；进行中的右键手势不会退出。

• 邮政快车：左键按住刹车，右键按住加速，中键点按投递/补充邮袋。让邮袋吊架对准车门再出手，正中和高速有奖励；限速桥、红灯和牛羊靠近时要刹车。时刻表耗尽，本局结束。旧选轨、鸣笛和分步练习已被新玩法替代。
• 萤火虫之夜：左键按住慢走，右键按住小跑，中键点按挥罐；满能量时双击中键放光。捕获补光，挥空或碰到危险会损失光；光耗尽结束。
• 双线攀岩：按画面提示交替点左右键抓点，中键换到另一条路线；换线后手位可能改变。冰点需按住对应手，碎石点要快走。看到落石警告或前路断点，及时换线；握力耗尽结束。
• 雪崩速降：左右键按住转弯，中键点按跳跃；从跳台起飞后，在空中点中键转体。连续旗门需要横向换位，连门提速，漏门或撞树会让雪崩逼近；被追上结束。
• 风层邮差：左键按住放气下降，右键按住加热上升，中键点按投信。看风向箭头选择风层，留出信件下落的提前量；正中、金邮筒和高空投递有奖励。避开树、鸟和雷云光柱；燃料耗尽结束。
• 火箭登月：左右键按住移动，中键在点火/分离绿区按下，飞行时点按加速，奔月转移按光圈节奏操作。靠近月面点按反推减速，对准着陆台；燃料耗尽或船体归零会失败，平稳着陆后播放插旗演出。

四、两款竖屏游戏

• 跳一跳：按住OK蓄力、松开起跳，下键切换角色、长按下键重新开始；落空结束，双击上键回地图。
• 深潜：OK开始/换向，按住下键俯冲，单击上键暂停/继续；避开障碍，氧气耗尽结束，双击上键回地图。

五、保存、设置与预览范围

正常结束一局后保存最佳纪录和印章；自动测试分数不写入存档。护照亭设置可调音量、亮度、扬声器与休眠。首次安装默认扬声器开启，可在设置中关闭；默认无操作300秒休眠，按上键唤醒。内置状态页版本文字仍为v0.1.0，本次安装包以社区更新说明和GitHub v0.2.0为准。
